# Portfolio media

## Portrait

Add your hero photo as `portrait.jpg` in this folder. Recommended crop: upright
portrait around 1200 × 1500. JPG or rename to match; WebP also works if you
update `components/HeroPortrait.tsx`.

## Project media

Place optimized project images and videos here, then add their root-relative
paths to the matching record in `data/projects.ts`.

Recommended image format: WebP or AVIF, 1600 × 1000 maximum. Keep filenames
lowercase and project-specific, such as `ruka-v2-wrist.webp`.
